Entry for the [make.fun bounty "The Internet in One Word"](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b?ref=jfeejy4f).

The whole internet, in a single word:

```
doomscroll
```

## Run it

```bash
python3 main.py
```

`main.py` reads `word.txt` (resolved next to the script, never by relative
cwd) and prints exactly that one word — nothing else.
